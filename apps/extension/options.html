Vitrinka recorder

Settings

The recorder talks to your vitrinka instance. The simplest way in is Link this browser: vitrinka shows a code, you approve it in a signed-in tab, and this browser receives a recorder token that can only create sessions in the workspace you pick — nothing else. A vkp_ personal token still works for an account that records into several workspaces. Project ↔ domain mapping lives in each vitrinka project's settings. If the vitrinka CLI is set up on this machine these are filled in for you.

Recorder data

Captured events and screenshots are held on disk until vitrinka has them — an outage never discards a recording. Data belonging to a session vitrinka has already finished is cleared automatically; a live recording is never touched.
